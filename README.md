This repo accompanies the following article:

Lacza, H., Mizuno, A., Williams, C., Lagisz, M., and Nakagawa, S. (2026). One dataset, four meta-analyses: synthesising mean effects and heterogeneity within and among populations. Biology Open. https://doi.org/10.1242/bio.062872

The repository provides the data, R scripts, and online tutorial accompanying the article.

The tutorial demonstrates four complementary meta-analytic approaches:

1. Meta-analysis of mean effects using the log response ratio (lnRR).
2. Meta-analysis of within-group variability using the log variability ratio (lnVR) and log coefficient of variation ratio (lnCVR).
3. Multilevel location-scale meta-regression of mean effects.
4. Multilevel location-scale meta-regression of variability effects.

The analyses show how a single dataset can be used to examine mean effects, within-group variability, and heterogeneity within and among studies.
